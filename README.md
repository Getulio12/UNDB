# UNDB

Atividades de Algoritmo e Programação.

## Atividade de 28/10/2026

- [Ver o programa em Python](atividade/atividade.py)
- [Ler a explicação passo a passo](atividade/README.md)

O programa resolve as seis questões da atividade: coleta e validação de três notas, cálculo da média, situação acadêmica, registro de vendas até a meta, relatório de vendas e classificação do faturamento.

## Executar no VS Code

1. Instale o Python 3 e a extensão Python da Microsoft no VS Code.
2. Abra a pasta deste repositório no VS Code.
3. Abra `atividade/atividade.py` e use **Executar Arquivo Python**, ou execute no terminal:

```bash
python atividade/atividade.py
```

Dependendo da instalação, use `python3` ou, no Windows, `py` no lugar de `python`. O programa usa somente a biblioteca padrão do Python e aceita números com vírgula ou ponto decimal.
